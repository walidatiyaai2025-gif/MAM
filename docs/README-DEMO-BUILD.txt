MAM Offline Demo build output

Run the repository P12 setup build. The generated setup directory contains:
- DiwanMAM-Desktop-Setup-<version>-x64.exe
- DiwanMAM-Server-Setup-<version>-x64.exe
- DiwanMAM-Demo-Setup-<version>-x64.exe

The Demo EXE is the standalone Windows 11 offline installer.
Open after installation: http://demomam.da.gov.kw/
Database: embedded SQLite.
SQL Server: not required.
Internet: not required at runtime.
